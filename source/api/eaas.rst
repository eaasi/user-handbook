EaaSI API
===========

Using the EaaSI API, authenticated users can:

  - query and gather metadata about the resources in a node
  - perform certain actions programatically, including some not incorporated into the EaaSI UI
  - interact with the experimental "UVI"; see :ref:`uvi`
