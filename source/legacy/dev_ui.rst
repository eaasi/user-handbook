Legacy UI
=========

Starting with the 2020.03-beta release, the EaaSI platform merged PortalMedia's work to create a
new user experience for the Emulation-as-a-Service stack. The User Guide section of this Handbook
reflects those changes and available features.

However, the "legacy" user interface originally developed by the bwFLA project (and still used by the
OpenSLX team for developing new features for the core EaaS stack) may remain relevant in some cases. (It is currently still used in EaaSI Docker desktop deployments, and 
may be visible in demos of new features)

For this reason, legacy materials from the User Handbook will be maintained in this section, for 
reference.
