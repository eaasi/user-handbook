Legacy UI
=========

Starting with the 2020.03-beta release, the EaaSI platform merges PortalMedia's work to create a
fresh, stable, and attractive user experience for the Emulation-as-a-Service stack. The User Guide
reflects those changes and available features.

However, the "legacy" user interface originally developed by the bwFLA project (and still used by the
OpenSLX team for developing new features for the core EaaS stack) may remain relevant for some time as
the EaaSI project transitions. (It is currently still used in EaaSI Docker desktop deployments, and 
may be visible in demos of new features, etc.)

For this reason, legacy materials from the User Handbook will be maintained in this section, for 
reference.
