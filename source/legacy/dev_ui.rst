Dev UI
=========

Starting with the 2020.03-beta release, the EaaSI platform merges PortalMedia's work to create a
fresh, stable, and attractive user experience for the Emulation-as-a-Service stack. The User Guide
reflects those changes and is primarily intended to guide users in the "production" UI.

However, the "legacy" user interface originally developed by the bwFLA project (and still used by the
OpenSLX team for developing new features for the core EaaS stack) is currently still accessible in EaaSI
installations. This "Dev UI" can be useful for troubleshooting purposes, transitioning experienced EaaS 
users and resources to the production interface, and is currently still used in EaaSI demo Docker
deployments. It also may be used as a space for advanced EaaSI Network users to test cutting-edge features
created for the EaaS stack that have not yet been fully integrated into the production interface.

For these reasons, legacy materials from the User Handbook will be maintained in this section, for
reference purposes.
