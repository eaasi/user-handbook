.. Installation and Configuration

Installation and Configuration
*******************************

For purposes of network security, EaaSI node representatives and system administrators will be provided guidance for installing and configuring their instance of the EaaSI platform on an individual basis and via private documentation.

For guidelines to install and run a local instance of the open source EaaS core, see `<http://eaas.uni-freiburg.de/docs/index.html>`_.
