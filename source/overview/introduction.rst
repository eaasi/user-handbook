.. Introduction to EAASI

Introduction
************

This User Handbook is a product of Yale University. It is intended to help new users navigate and perform common tasks within the EAASI platform, and give prospective users a sense of the platform’s functionality and workflows.

This section of the EAASI User Handbook refers to the `latest` or "Next-Gen" version of EAASI that remains under active development. This part of the Handbook will be periodically updated in order to give current and prospective EAASI users a sense of the new look, feel, and features of the re-architected platform, before it is actively deployed.

If you would like guidance on using the `v2021-10` version of the EAASI platform that is currently available to users at Yale University and select partners, use the version switcher (either under the logo at top left of the sidebar, or in the flyout menu at the bottom right of your screen) to select the `v2021-10` version of the User Handbook.

The EAASI User Handbook is hosted and published through `Read the Docs <https://about.readthedocs.com/>`. For any technical issues encountered
*with this site* or suggestions/requests for expanded documentation, please feel free to start a thread in the `EAASI Community Forum <https://forum.EAASI.cloud>`_ or contact Yale
`Software Preservation and Emulation Librarian Ethan Gates <https://web.library.yale.edu/sd/staff/45476>`_, who maintains this site.

.. warning::
  The EAASI platform is maintained by a small team. Users will experience bugs and inconsistencies not described in this
  documentation. Please see :ref:`bugs` and :ref:`community` for assistance.
