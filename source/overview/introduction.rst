.. Introduction to EAASI

Introduction
************

This User Handbook is a product of Yale University. It is intended to help new users navigate and perform common tasks within the EAASI platform, and give prospective users a sense of the platform's functionality and workflows.

This section of the EAASI User Handbook refers to the legacy ``v2021-10`` version of EAASI in use at Yale University and by selected partners. This codebase, developed during EAASI's grant-funded phase, is no longer actively maintained and the EAASI team cannot support general deployment and use beyond what is offered in this Handbook. 

Development resources have been prioritized to a significant, modernized re-architecture of the EAASI platform, dubbed "Next-Gen EAASI." To preview the new look, feel, and features of "Next-Gen EAASI", use the version switcher (either under the logo at top left of the sidebar, or in the flyout menu at the bottom right of your screen) and select the ``latest`` `version <https://eaasi-user-handbook.readthedocs-hosted.com/en/latest/>`_ of the User Handbook.

The EAASI User Handbook is hosted and published through `Read the Docs <https://about.readthedocs.com/>`_. For any technical issues encountered
*with this site* or suggestions/requests for expanded documentation, please file an Issue on the `User Handbook GitHub repository <https://github.com/eaasi/user-handbook/issues>`_ or contact Yale's
`Software Preservation and Emulation Librarian <https://web.library.yale.edu/sd/staff/45476>`_ Ethan Gates, who maintains this site.

.. warning::
  The EAASI platform is maintained by a small team. Users will experience bugs and inconsistencies not described in this
  documentation. Please see :ref:`bugs` for assistance.
