EAASI User Forum
===================

The `EAASI User <https://forum.eaasi.cloud/>`_ Discourse forum is an open space, not just for reporting bugs, but also public discussion regarding emulation, software preservation, configuration workflows, assistance with using legacy software applications, and other topics related to the EAASI Research Alliance. Please sign up for an account today and join in the conversation!
