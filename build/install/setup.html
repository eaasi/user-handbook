Setup¶

Preconditions¶

General EaaSI infrastructure layout (tbd).

  • A EaaSI gateway machine - ssh shell access - sudo capabilities, make sure you do not need a password to use sudo - at least 10 Gb free disk space for the EaaSI installation

Prepare for setup¶

  • Checkout eaas-ansible
  • Build the deployment docker (optional):
    • run docker build -t eaas/eaasi-deploy . (you may need to prepend sudo depending on your installation
  • Setup the ssh-keys for deployment:
    • go inside eaas-ansible/example
    • run docker-compose -f setup-docker.yaml pull (only if you haven’t build the docker youself (see above)
    • run docker-compose -f setup-docker.yaml up:
      • you should have a ssh directory in your working directory
    • copy the keys to your remote server, run ssh-copy-id -i ssh/id_rsa user@host. the username should match the remote user with sudo capabilities.

Configure the EaaSI Gateway¶

A minimal gateway.yaml file should look like:

---

host:
#  sslHostname: "eaasi.emulation.cloud"
  remoteUser: "klaus"
  eaasHome: "/var/data/eaas-home"
  buildPath: "/var/data/eaas-build"
  eaasTmp: "/tmp"
  sshPort: 22

docker :
  image: "eaas/eaas-appserver"
  portMapping: "80:8090"
  port: "80"
  cleanup: false
  sslEnabled: "false"
  imageArchiveVolume: "/eaas/archive"

ui:
  gitBranch: "master"
  hostname: "hostname.dns.internal"
  enableScreenshooter: true
  enableSnapshots: false
  buildFromSource: true
  deployAdminUI: true
  deployUserUI: true

  #httpAuth:
  #  user: "usernamme"
  #  password: "randompassword"

eaas:
  gitBranch: "master"
  softwareArchiveId: "SoftwareArchive"
  objectArchiveId: "default"
  buildFromSource: true
#  earTarget: "/home/klaus/eaas-server.ear"

A minimal hosts should look like:

[gateway]
hostname1.dns.internal
